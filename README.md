## 📖 项目概述
本项目是 **SpringAI-Chat-Backend 后端的专属移动端前端**，基于 **Vue3 + JavaScript** 开发，专为移动端AI聊天场景设计。
项目实现了从开屏广告、用户登录注册、AI智能对话到个人中心的全流程交互，所有界面**仅适配移动端**，采用 WebSocket 实现消息实时推送，完美对接后端的AI会话、积分计费、智能体、RAG等全部核心功能，开箱即用。

## 🎯 项目定位
- 配套后端的**移动端专属AI聊天前端**，无桌面端适配
- 完整的用户体系 + AI聊天交互 + 个人中心闭环
- 低侵入、易部署，直接对接后端接口即可运行
- 贴近主流AI聊天APP的交互体验

## ✨ 核心功能模块
### 1. 启动与用户认证模块
- 精美**开屏页面**，提升应用体验
- 完善的**登录、注册页面**，表单校验齐全
- 登录说明：`填充注册账号` 为后端默认数据库账号，**未注册无法登录**，需先完成注册
- 验证码规则：**无真实邮箱校验，验证码固定填写 6个1（111111）**

### 2. 移动端主界面
- 标准**底部导航栏**布局，操作便捷
- 适配手机屏幕，**仅支持移动端预览**
- 页面切换流畅，路由跳转无卡顿

### 3. AI 聊天核心模块（核心功能）
- 双模式切换：
  - **消息展示模式**：切分模式（逐句输出）/ 正常模式
  - **对话模式**：角色模式 / 正常会话模式
- 消息推送：**全量基于 WebSocket**，用户登录成功后自动建立长连接
- 支持消息发送、接收、历史记录展示、会话管理
- 完美对接后端解耦AI引擎、打断续答、积分计费功能

### 4. 个人中心模块
- 标准用户个人中心页面
- 支持功能：
  - 修改个人资料
  - 积分充值（对接后端计费体系）
  - 会话收藏管理
  - 意见反馈提交

## ⚠️ 重要使用规范（必看）
1. **测试方式**
   本项目**仅适配移动端**，**禁止使用桌面浏览器直接测试**
   ✅ 正确方式：在浏览器的**手机模拟器模式**下运行（F12 → 切换手机设备）

2. **登录注册规则**
   - 填充账号仅为示例，必须手动注册才能登录
   - 注册验证码统一填写：`111111`，无需真实邮箱

3. **WebSocket 连接**
   长连接在**登录成功后自动建立**，未登录无法接收AI消息

4. **前后端关联**
   必须启动配套的 SpringAI-Chat-Backend 后端服务，前端才能正常运行

## 🚀 快速部署指南
### 一、环境要求
- Node.js 16.0 及以上版本
- npm / yarn 包管理工具

### 二、部署步骤
1. 克隆项目到本地
2. 安装项目依赖
   ```bash
   npm install
   ```
3. 配置后端接口地址（修改请求基础路径，对接本地/服务器后端）
4. 启动开发服务
   ```bash
   npm run dev
   ```
5. 打开浏览器，开启**手机模拟器**，访问项目地址即可使用

### 三、构建生产版本
```bash
npm run build
```
构建完成后，将 `dist` 目录部署到服务器即可上线
